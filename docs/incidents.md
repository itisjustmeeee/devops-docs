# Журнал типовых инцидентов

| Инцидент | Наблюдаемый признак | Первичный источник диагностики |
| --- | --- | --- |
| Неиспользуемая переменная | Красная проверка `pylint` в PR | Журнал шага Static analysis |
| Недостаточные права пцбликации | `build` успешен, `deploy` получает OIDC-токен | Журнал `deploy-pages` и блок `permissions` |
| Битая ссылка | `mkdocs build --strict` завершается ошибкой | Журнал шага Build documentation |
| Старая версия после успешного деплоя | Зеленый workflow, прежнее содержимое в браузере | URL окружения, время публикации, кэш браузера |

## Правило разбора

В разборе указываются симптом, затронутый компонент, доказательство из журнала, причина, исправление и проверка восстановления. Ответ "перезапустил и заработало" без установления причины неполон.
